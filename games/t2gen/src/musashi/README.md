Place upstream Musashi sources here before enabling CONFIG_GAMES_T2GEN_MUSASHI:
- m68k.h
- m68kconf.h (configure for 68000, not 68020)
- m68kcpu.h
- m68kcpu.c
- m68kops.h
- m68kops.c (generated by Musashi's m68kmake)

Musashi project: https://github.com/kstenerud/Musashi
Check the upstream license and generated source requirements.
This ZIP intentionally does NOT include Musashi sources, so enabling the
option without them will fail to compile. The default disabled option
retains the v3 diagnostic and builds without an external dependency.
